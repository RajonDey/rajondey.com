# My Personal WordPress Website

This repository contains the source code and structure for my personal WordPress website.

## Description

This is the codebase for my personal website, which showcases my portfolio, blog posts, and projects. It's built using WordPress with a custom theme and carefully selected plugins for enhanced functionality.


## Installation

1. Clone this repository: `git clone https://github.com/yourusername/your-repo-name.git`
2. Install WordPress on your local machine or web server
3. Copy the contents of this repository to your WordPress installation directory
4. Create a new `wp-config.php` file (do not commit this to the repository)
5. Set up a new database and configure wp-config.php with your database credentials
6. Generate new salts for wp-config.php (https://api.wordpress.org/secret-key/1.1/salt/)
7. Activate the theme and install required plugins

## Repository Purpose

This GitHub repository is primarily used for version control and as a backup for my website's code. Major updates are typically pushed every 6-12 months.
